# Учебные проекты

Каждый проект Yonote размещается в отдельной директории:

```text
json/
```

Все задачи с `Проект = json` работают с `projects/json/`. При создании первой
task-ветки интеграция автоматически добавляет `README.md` и `main.py`, если
директории проекта ещё нет. Существующий проект не перезаписывается.

Значение `Проект` — уникальный технический ключ из латинских строчных букв,
цифр и одиночных дефисов длиной до 64 символов. Оно используется как имя
директории без транслитерации и обрезки.

К завершению задачи внутри директории должны находиться:

- `README.md` с условием задачи и критериями готовности;
- Python-код решения;
- тесты с именами `test_*.py`.
