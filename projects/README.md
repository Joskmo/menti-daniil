# Учебные проекты

Каждая задача Yonote размещается в отдельной директории:

```text
PY-001-short-title/
```

При создании task-ветки интеграция автоматически добавляет `README.md` и
`main.py`, если директории проекта ещё нет. Существующий проект не
перезаписывается.

К завершению задачи внутри директории должны находиться:

- `README.md` с условием задачи и критериями готовности;
- Python-код решения;
- тесты с именами `test_*.py`.
